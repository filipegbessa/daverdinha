# Questionário: políticas da loja online

Este questionário serve para montar os textos de **Trocas e devoluções** e as informações de **Entrega e retirada** que vão aparecer no site. Basta responder do jeito que a Daverdinha trabalha hoje. Quando houver opções, marque uma ou escreva a sua. Com as respostas, escrevemos o texto final para você revisar antes de publicar.

O que a lei já obriga vale de qualquer jeito, mesmo que a resposta seja diferente. Os principais pontos estão nos quadros "Pela lei". Antes de publicar, vale uma conferida com o contador ou um advogado.

> As perguntas sobre ingressos de oficinas, aulas e eventos ficam para depois, quando a venda de ingressos pelo site entrar (`docs/questionario-ingressos.md`).

## Parte 1: entrega

> **Pela lei (Decreto 7.962/2013):** a loja online precisa informar de forma clara as condições de entrega, incluindo o prazo.

1. Depois que o pagamento é aprovado, em quantos dias vocês entregam um produto de **pronta entrega**?
   - ( ) No mesmo dia, se o pedido for feito até ___h
   - ( ) Em até ___ dias úteis
   - ( ) Outro: ____
2. Em quais dias da semana e horários vocês entregam?
3. Vocês avisam o cliente antes de sair para a entrega (ex.: mensagem no WhatsApp com o horário previsto)?
4. Se não tiver ninguém para receber:
   - ( ) Tentamos de novo sem custo
   - ( ) Tentamos de novo, cobrando outro frete
   - ( ) O cliente passa a retirar no ateliê
   - ( ) Outro: ____
5. Outra pessoa pode receber no lugar do cliente (porteiro, vizinho, familiar)?
6. Plantas e vasos vão embalados de algum jeito especial? Tem algum cuidado que o cliente deve ter ao receber (ex.: tirar da caixa logo, não deixar no sol)?

## Parte 2: retirada no ateliê

O endereço, os dias e horários e as instruções da retirada já são preenchidos por você no admin (Loja). Aqui são só as regras.

7. Depois do pagamento, em quanto tempo o pedido fica pronto para retirar?

## Parte 3: trocas e devoluções

> **Pela lei (Código de Defesa do Consumidor):**
> - Em compra pela internet, o cliente pode desistir em até **7 dias** depois de receber, sem precisar explicar o motivo, e recebe o valor de volta, **frete incluído**. Nesse caso o frete de devolução também fica por conta da loja (art. 49).
> - Produto com defeito: o cliente tem **30 dias** para reclamar de produto que estraga rápido (plantas, mudas) e **90 dias** para produto durável (vasos, cerâmica) (art. 26).
